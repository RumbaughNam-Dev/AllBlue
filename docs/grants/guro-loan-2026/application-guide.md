# 2026 구로구 중소기업·소상공인 1년 무이자 특별보증 융자 — 신청 안내

- 공고: 서울특별시 구로구공고 제2026-449호 (2026-02-27), 원문 `sources/notice.pdf`
- 접수: 2026-02-27 ~ **자금 소진 시** (평일만)
- 규모: 총 212.5억 원, 이 중 **1년 무이자는 100억 원 한도** (소진 시 무이자 지원만 마감되고 일반 특별보증은 계속될 수 있음)

## 보증 거절 사유 체크리스트 (붙임3, 하나라도 해당하면 거절)
- [ ] 최근 1년 안에 신보·기보·신용보증재단 보증을 받고 잔액이 남아 있음 ← **예전 대출 시도 때 보증을 받았는지 확인**
- [ ] 연체 대출금 보유 / 최근 3개월 내 30일 이상 연체 또는 10일 이상 연체 4회
- [ ] 최근 6개월 내 신용도판단정보 등록, 소유 부동산 압류·가압류
- [ ] 국세·지방세 체납
- [ ] 최근 3개월 내 카드사·저축은행 등 3곳 이상에서 대출
- [ ] 카드 현금서비스 4곳 이상 또는 합계 1천만 원 초과
- [ ] 신보와 기보 보증을 동시에 이용 중

## 신청 순서 (개인 단독대표 = 모바일 비대면 가능)
1. **전화 확인 (오늘)**
   - 구로구청 지역경제과 기업지원팀 ☏ 02-860-3409: "1년 무이자 100억 한도가 남았는지, 지금 신청해도 무이자 적용되는지"
   - (선택) 서울신용보증재단 구로종합지원센터 ☏ 02-2174-4458: 이전 대출 거절 이력이 심사에 어떤 영향이 있는지
2. **모바일 신청**
   - '서울신용보증재단' 앱 설치 (앱스토어/플레이스토어) → 본인 인증 로그인
   - 보증신청: 신청금액(최대 5천만 원), 대출은행 선택 → 요청 서류 촬영해 업로드
   - 은행은 가까운 곳 선택 (예: 우리은행 고척동지점, 하나은행 고척동지점, 국민은행 고척동지점, 고척새마을금고)
3. **재단 상담 전화 받기** — 직원이 순차적으로 전화 → **"구로구 1년 무이자 특별보증 신청"이라고 꼭 말하기**
4. **구로구청 지역경제과 방문** (가마산로 245) → 특별보증 추천서 **2부** 발급 (재단 제출용·은행 제출용)
   - 신분증, 사업자등록증 사본 지참
5. **추천서 제출** — 재단 제출용은 앱 '기타서류 제출'로 업로드, 은행 제출용은 대출 실행 때 은행에 제출
6. 보증서 발행 → 은행 방문해 대출 실행

## 준비물
- 대표 신분증, 사업자등록증 사본
- 재단이 추가로 요청할 수 있는 것: 부가세 과세표준증명(2026년 1기 신고분이 매출 증빙), 매출 세금계산서, 통장 거래내역 등

## 참고
- 신용평가·재무상태 심사로 대출이 안 될 수 있음 (공고문 명시)
- 같은 재단의 서울시 중소기업육성자금과는 중복 제한이 있을 수 있음 — 상담 때 확인
