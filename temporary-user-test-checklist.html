임시 사용자 전체 테스트

처음 생성하는 순간부터 가입 사용자로 연결한 뒤까지.
순서대로 실행하고, 기대 결과가 맞으면 체크하세요. 이전 화면 개선 사항도 함께 검사합니다.

이번 검사 기록

실행 환경마다 따로 저장됩니다. 이름·일정에는 같은 접두사를 붙이면 찾기 쉽습니다.

계정 A → 임시 사용자 T1·T2 → 가입 사용자 B
A는 등록자 강사, B는 연결받을 가입 사용자, C는 다른 강사입니다. T3는 권한 비교용입니다.
기본 검사를 먼저 마친 뒤 연결하세요. 연결 후 원래 임시 사용자로 되돌리는 앱 기능은 없습니다.

앱 상태는 실제로 바뀝니다. 이 HTML의 체크는 테스트 결과 기록일 뿐 앱이나 DB에 요청을 보내지 않습니다. 파일은 외부 라이브러리·네트워크 없이 작동합니다.
